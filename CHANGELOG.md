# Changelog

## 1.0.0

- Share for .NET MAUI on Android and iOS beyond MAUI `Share`
- `SharePlus.ShareTextAsync` / `ShareFileAsync` / `ShareFilesAsync`
- Title, Subject, MimeType, Preview, TargetApp, and TemporaryFileHandling
- WhatsApp, Email, Messages, Files, Nearby Share, and AirDrop targets
- Dedicated FileProvider root (`shareplus/`) so the entire app cache is not exposed
- ClipData + `GRANT_READ_URI_PERMISSION` on Android file shares
- Sample app and unit tests
